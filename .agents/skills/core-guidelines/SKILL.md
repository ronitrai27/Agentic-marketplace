# Core Guidelines

Always adhere to these guidelines for all interactions:

1. **Direct Execution First**:
   - Never over-reason, over-think, or search extraneous files when a specific, direct instruction is given. Act immediately.

2. **Verify Syntax & Errors**:
   - Always verify JSX, TSX, TypeScript, and syntax integrity after making any edits before returning. Never leave broken tags or syntax errors.

3. **Clarify & Suggest Proactively**:
   - If not completely clear about a task, ask first rather than guessing.
   - Always present new ideas and cleaner alternatives when clarifying.
