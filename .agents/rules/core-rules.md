# Antigravity Agent Rules

These rules must always be followed strictly across all tasks:

1. **Direct Execution First**:
   - Never over-reason, over-think, or search through unnecessary files when a direct, specific task is provided. Act immediately.

2. **Verify Syntax & Errors**:
   - Always verify JSX, TypeScript, and syntax integrity after making any edits before returning. Never leave broken tags, unclosed brackets, or compilation issues.

3. **Clarify & Suggest Proactively**:
   - If user requirements are ambiguous or underspecified, ask first before making assumptions.
   - Proactively suggest better, cleaner, or innovative ideas alongside your clarifications.
