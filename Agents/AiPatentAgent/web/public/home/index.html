A single number for how new your disclosure reads against the closest prior art — higher reads as more novel — plus the claims and elements that moved it.

§2(1)(j) / §2(1)(ja) verdict

Novelty vs. inventive step, separated.

§2(1)(j) asks whether a single reference already contains every element. §2(1)(ja) asks whether combining what exists would be obvious. The run names the risk you face — clear, partial overlap, lack of inventive step, or lack of novelty.
